# CampusFix

Smart Campus Issue Reporting and Resolution System

## About
CampusFix is a web-based application that helps students
and faculty report campus problems and track their resolution.

## Main Features
- User registration and login
- Submit campus complaints
- Upload issue images
- Track complaint status
- Admin complaint management
- AI-assisted complaint categorization
